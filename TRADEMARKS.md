- Using "turna" or the logo as (part of) **your** product name, company name,
  domain, or app store listing.
- Any use that suggests **official status, endorsement, partnership, or
  affiliation** with the owner or the upstream project when none exists.

## Forks

You are free to fork the code (that is what open source is for). When you
publish a fork that is not a verbatim redistribution, choose a distinct name and
logo, and make clear it is an independent project derived from turna — not turna
itself.
