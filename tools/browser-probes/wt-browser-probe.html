TURN over WebTransport

A TURN client written in browser JavaScript, speaking HTTP/3. It exists to be not the server's code: the Rust client that verified this path shares a library and one reading of the spec with the server, so anything both get wrong stays invisible to it. Chrome's WebTransport stack does not.

HTTPS with a certificate the browser trusts. Self-signed will not do — WebTransport has no exception dialogue.
